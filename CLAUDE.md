## Architecture

**Next.js 16 App Router** real estate listing platform with TypeScript and Tailwind CSS 4.

### Key directories

- **`/app`** — Pages and API routes
  - `layout.tsx` — Root layout; wraps everything in `FormProvider`, mounts `Header`, `Footer`, `GoogleAnalyticsTracker`
  - `page.tsx` — Home page composing section components
  - `project-listing/[city]/[slug]/[enquiry]/` — Dynamic property detail pages
  - `api/contact/route.ts` — POSTs form submissions to a Google Apps Script webhook
  - `sitemap.ts` — Auto-generated XML sitemap

- **`/components`** — All UI components; no sub-grouping convention, flat directory
- **`/context`** — React context + static data
  - `FormContext.tsx` — Global modal form state (`isOpen`, `openForm`, `closeForm`)
  - `utils/ProjectDetails.tsx` — Static project/property data (source of truth for listings)
  - `utils/AboutPageData.tsx` — Testimonials and about page content
- **`/models/types.tsx`** — Shared TypeScript interfaces (`PropertyItem`, `PropertyDetails`, `FeatureSectionProps`, etc.)

### Data flow

**Note: the previous description of this section was wrong and is corrected here (2026-09-19).** `context/utils/ProjectDetails.tsx` is dead code — nothing under `app/`, `components/`, `lib/` or `hooks/` imports it. The real sources are:

- **Listings and projects** — fetched at request/build time from an external scraped feed, `https://homz-scrape.vercel.app/api/data` (`lib/scraping/homzbackend.ts`). Server-side caching in `lib/listings/segmentCache.ts` (1h TTL, `UPSTREAM_LIMIT = 25_000`) and `lib/intelligence/projects.ts` (30min). Live volumes: ~21K Sale, ~13K Rent, ~2,098 Gurgaon projects.
- **Auth, admin, wishlist, agent listings, status** — MongoDB (`lib/mongodb.ts`).
- **Editorial** — typed TS modules under `lib/content/blog/` (25 posts, Zod-validated by `lib/content/blogPostSchema.ts`) and `lib/content/buyerGuides.ts`.
- **POI/geo** — `data/osm/*.json`, generated by `scripts/generate-osm-pois.mjs`, read via `lib/intelligence/osmPlaces.ts`.

Form submissions go through `/api/contact` → Google Apps Script → Google Sheets. That endpoint has no validation and no idempotency key, and forwards the webhook's own body verbatim — see `docs/seo/implementation-status.md`.

### Commands that actually work

`npm run build` uses Turbopack and OOMs on most machines — use `npx next build --webpack`. But anything touching Next's reserved metadata routes (`sitemap.xml`, `robots.txt`, `favicon.ico`, `manifest.json`) **must** also be checked with a plain `npx next build`, since Vercel builds with Turbopack and `--webpack` does not catch those conflicts. There is no test framework. `npx eslint .` has a pre-existing baseline of 22 errors / 10 warnings.

### Image handling

Remote images are allowed only from `static.squareyards.com` and `loangateway.urbanmoney.com` (configured in `next.config.ts`). Always use Next.js `<Image>` for these sources.

### Styling

Tailwind CSS 4 (PostCSS plugin). Custom font family `"Zolina"` defined in `tailwind.config.ts`. No CSS Modules or styled-components.
